# RandomCrestMod 使用说明（纷乱）

**简体中文** | [English](https://github.com/LIFELAN/RandomCrestMod/blob/master/README.en.md)

> 已发布到 Thunderstore（社区 **Hollow Knight: Silksong**），推荐用 mod 管理器（r2modman / Gale /
> Thunderstore Mod Manager）搜索 **RandomCrestMod** 安装，会自动处理好 BepInEx 依赖。

一个《空洞骑士：丝之歌》BepInEx 模组：新增一个纹章 **「纷乱」**（英文 **Chaos**）。
装备它之后，攻击、缚丝、工具、法术全部随机 —— **你永远不知道下一秒会发生什么**。

纹章在每个存档**开局即解锁**，可在**任意长椅切换**，**六个槽位默认全部解锁**。
所有随机效果**只在装备纷乱时生效**，完全不影响其他纹章。

---

## 安装

1. 先安装 **BepInExPack Silksong**（用 mod 管理器会自动装好）。
2. 将 `RandomCrestMod.dll` 放入：

   ```
   <游戏目录>/BepInEx/plugins/lifelan-RandomCrestMod/RandomCrestMod.dll
   ```

   （用模组管理器安装，或自行 `dotnet build -c Release` 构建，构建脚本会自动复制。）
3. 启动游戏，在任意长椅选择 **纷乱** 即可。

## 功能

以下全部**只在装备纷乱时生效**。卸下后，其他纹章的行为与游戏原版完全一致。

| 功能 | 说明 |
| --- | --- |
| 随机攻击 | 每次攻击随机使用某个纹章的攻击模组，你按下的方向（普通 / 上 / 下 / 蹬墙 / 冲刺 / 蓄力斩）保持不变。 |
| 随机缚丝 | 每次缚丝随机使用某个纹章的缚丝效果。 |
| 随机工具 | 每次投掷随机变成游戏内任意一个红色工具，无论是否已获得。 |
| 工具连投 | **需持有「大黄蜂雕像」**：一次投掷会连续投出多次——每级工具袋 **+1** 次，装备 Quick Sling（迅捷投掷）再 **+1** 次；每次连投都会重新随机一个新工具。**没有雕像时投掷与游戏原版完全一致**（单发；迅捷投掷仍是原版二连）。 |
| 随机法术 | 每次释放灵丝技能随机变成 6 种法术之一。除十字绣外，每次施放的**首个扣丝**有 **3%×已获得法术** 的概率**立即退还本次消耗**（丝轴补丝动画，与十字绣一致）；十字绣仍按真格挡必退。 |
| 随机嘲讽 | 按下嘲讽键（R3 / V）随机使用三种形态之一：普通 **80%**、野兽纹章吼叫 **14%**、投掷环特殊动作 **6%**；野兽形态会连专属动作一起切换。 |
| 嘲讽献祭 | 装备纷乱时，**在地面完整播完**一次嘲讽且碎片 ≥ 80，会消耗 80 碎片并按随机到的形态给念珠：普通 0~50、野兽 60、投掷环 80；碎片不足 80 则嘲讽只是表演，不扣不给。 |
| 十字绣强化 | 装备纷乱时，十字绣摆好架势后即使未被攻击也会自动反击；自动反击的**后退高光必定播放**，但**只有 50% 概率真正打出追击伤害**，未命中时只留高光便收招。**真招架永远命中**并保留原版火花。其它纹章的十字绣完全原版。 |
| 诅咒缚丝 | 装备纷乱时，随机缚丝有 **5%** 概率变成**诅咒缚丝**：扣除**全部灵丝**，同时每扣 **1 格**灵丝补偿 **10 枚念珠**。其它纹章的缚丝完全原版。 |
| 大黄蜂雕像 | **多投能力的开关**。除游戏原版途径（Fixer 任务）外，新增两条获取方式：①**钟心镇**地图师区域（靠入口一侧）的一次性世界拾取，取走即**永久消失**，不检测纹章；②装备纷乱时用**随机抽到的储液针管**造成实质伤害，**每次使用奖励 1 枚**（一次使用的多段伤害只算 1 枚，多次使用累加，**无上限**）；**主动装备**的储液针管不奖励。雕像本身也可消耗换碎片；消耗后多投随之关闭。 |
| 工具次数 | 每次坐椅子前所有工具共享基础 **16 次**使用次数（可配置），每级工具袋再 **+25%**；补充**不消耗碎片**；每**收集**一件红色工具使本次投掷 **+2%** 概率不消耗次数（曲镰升级再 **+2%**，上限 40%；陷阱设置器与储液针管不计入）。 |
| 生质液瓶 | 随机掷到 **生质液瓶** 且已获得 **生质液腺** 时，蓝血回复由 **1 提升为 3**（无冷却）。 |
| 符文之怒 | 装备纷乱时，**符文之怒**（丝弹）的伤害**翻倍**。 |
| 自定义 HUD | 自定义缚丝外框、固定的"随机"工具 / 法术 HUD 图标、存档选择界面的自定义纹章 spool。 |
| 工具袋补碎片 | 装备纷乱时每**升级一次工具袋**（Tool Pouch）立即补充 **800 碎片**（受游戏碎片上限封顶；上限本身每级工具袋 +25%）；其它纹章上升级不补。 |

### 特殊工具处理

- **所有红色工具始终进入随机池**，包括 `Extractor`（**储液针管**）、`Silk Snare`（**陷阱设置器**）、
  `Rosary Cannon`（**念珠炮**）与 `Screw Attack`（**Delver's Drill** / 掘洞钻）——没有排除名单，也不提供开关。
  其中 **储液针管** 装备后会保持原版功能、不参与随机替换，任务可正常完成（HUD 显示原图标）；**陷阱设置器** 与其它红工具一样遵循随机原则（装备时会被替换、HUD 显示随机图标）。
- `Lightning Rod`（**Voltvessels** / 电枢球）每次抽取时在**流星锤**与**标枪**两种形态间随机，之后会还原玩家自己的形态设置。
- `Rosary Cannon`（念珠炮）始终保持**已充能**，并且在自定义使用循环期间被视为已装备，所以**长按会像原版一样持续开火**。

## 配置项

配置文件：`BepInEx/config/io.github.lifelan.randomcrestmod.cfg`

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `ToolUsesPerBench` | `16` | 坐椅子时所有工具补充到的**基础**使用次数（每级工具袋再 +25%）。 |
| `CursedBind` | `true` | 随机缚丝是否可能变成诅咒缚丝（固定 5%）。`false` 时永不出诅咒缚丝。 |
| `ParryAlwaysSucceed` | `false` | 十字绣自动反击是否必中。`false` = 50% 命中（默认），`true` = 必中。 |

> 三个配置项都在同一个**无名分组**里（旧版 `[Tools] ToolUsesPerBench` 需重新设置一次）。其余数值均已**写死**
> （经调试确定），不提供配置：随机攻击 / 缚丝 / 工具 / 法术 / 嘲讽 / 十字绣强化 /
> 法术概率退丝 / 生质液瓶强化 / 符文之怒伤害翻倍始终开启且仅限纷乱生效；工具连投需要
> **大黄蜂雕像**；诅咒缚丝固定 **5%** 概率、每格灵丝补偿固定 **10 枚念珠**；所有红工具始终在随机池（储液针管装备时保持原版）；Voltvessels 两种形态随机；
> Rosary Cannon 固定已充能且长按连发；自定义 HUD 外框 / 存档 spool / 随机图标固定开启，HUD 外框的偏移与
> 缩放也已固定。

## 注意事项

- 只有装备纷乱时随机效果才会触发；其他纹章完全不受影响（工具次数、补充花费、工具形态等都不会被改动）。
- 随机工具池包含你**尚未获得**的工具；随机法术为全部 **6 种**灵丝技能。
- 随机缚丝需要**满丝（9 格）**才会触发；灵丝不足时表现为原版"丝不够"。
- **工具连投**需要背包里持有**大黄蜂雕像**；没有雕像时工具投掷与游戏原版完全一致。
- **十字绣自动反击**只有 **50%** 概率打出追击伤害；失败时只播放后退高光，不再造成伤害。
- 纷乱**不计入游戏完成度**（其他纹章、工具、技能的完成度不受影响）。

## 构建

```sh
dotnet build -c Release
```

构建完成后会将 `RandomCrestMod.dll` 复制到 `BepInEx/plugins/lifelan-RandomCrestMod/`。
自定义美术资源位于 `Assets/`（纹章图标、HUD 外框、存档 spool、随机图标等），会嵌入 DLL。

游戏路径在 `SilksongPath.props` 中配置。
